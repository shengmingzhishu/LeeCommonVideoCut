# 项目上下文（video-cut · 前端）

> AI 启动开发前的必读摘要。完整规则见 `.trae/rules/`，详细 PRD 见 `AI漫剧剪辑师旧参考项目代码/docs/PRD-漫剧推广素材剪辑师.md`。

## 4. 命名速查

- 组件文件：`PascalCase.tsx`（如 `ProjectCard.tsx`, `Step5Preview.tsx`）
- 非组件文件：`camelCase.ts`（如 `projectService.ts`, `useTaskPoll.ts`）
- 类型文件：`.types.ts` 后缀（如 `project.types.ts`）
- 目录：`kebab-case`（如 `step-parallel/`）
- 业务对象类型：`Project`, `ProjectCreate`, `KeywordAnalysis`, `Article`, `ScriptResult`, `AudioResult`, `VideoMarker`, `MarkerSet`, `CutResult`, `FinalResult`, `GenerationHistory`, `TaskStatus`
- 步骤常量：`StepNum.STEP_INPUT = 1` ~ `STEP_COMPOSE = 7`

## 5. 与后端约定

- Base URL：`http://localhost:8000/api`（从 `import.meta.env.VITE_API_BASE_URL` 读）
- 请求拦截器：自动注入 `X-Trace-Id` header
- 响应统一处理：解 `{code, msg, data}`，code != 0 时触发全局错误 toast
- 长任务：`useTaskPoll(taskId, interval=1000)` 轮询 `/api/task/{task_id}`
- 视频预览：`/api/file/preview?path=xxx`（后端 Range 流式代理）

## 7. 关键技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 构建 | Vite | 快、HMR、原生 ESM |
| 框架 | React 18 | 与 PRD/旧参考生态一致 |
| 路由 | React Router v6 | 主流、SPA 友好 |
| 状态 | Zustand | 轻量、TS 友好、无 boilerplate |
| UI | Ant Design 5 | 与 PRD 深色科技风基线一致 |
| 样式 | CSS Modules + SCSS | 局部作用域，避免全局污染 |
| 表单 | React Hook Form + Zod | TS 类型安全 |
| 测试 | Vitest + Playwright | 与 Vite 生态一致 |
| 视频 | 原生 `<video>` + ref | 虚拟串播需要精细控制 currentTime |

## 8. UI 风格基线

- 背景 `#0f1117`、表面 `#1a1d27`、边框 `#2d3142`
- 主色 `#7c3aed`（紫）、成功 `#10b981`、警告 `#f59e0b`、错误 `#ef4444`
- 强调色 `#D85A30`（橙，关键动作如"确认裁切"）
- 字体：`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Microsoft YaHei'`
- 圆角：12px（卡片）/ 8px（按钮、输入框）

## 10. 卡点恢复机制（精简）

- 单个 bug 修复 3 次仍失败 → 暂停，落到 `docs/03-问题记录.md`，等待人工
- 后端字段变更 → 同步更新 `src/types/api/` 并校验 `tsc --noEmit`
- 与后端契约分歧 → 以 `cut-server/docs/02-项目上下文.md` §5 为准
