## 1. 项目基本信息

| 项 | 值 |
|----|-----|
| 项目名 | LeeCommonVideoCut（video-cut） |
| 描述 | 面向漫剧/视频推广素材的一键式本地化生产工具，7 步流程自动生成 9:16 竖屏推广视频 |
| 目标 | 让无剪辑经验的漫剧推广从业者一键产出推广视频；虚拟预览（0 IO）避免反复切片；多次生成保留历史版本 |
| 部署方式 | 本地化（Windows 10/11），后端 8000 + 前端 5173 |
| 用户规模 | 单用户本地使用 |

## 2. 业务流程（7 步）

| 步骤 | 输入 | 输出 | 前端页面 | 后端接口 |
|------|------|------|---------|---------|
| Step1 | 标题/作者/简介/视频目录/介绍目录 | 素材清单 | Step1Panel | POST /api/step1/load |
| Step2 | 素材清单 | 关键词拆解+搜索结果 | Step2Panel | POST /api/step2/analyze |
| Step3 | 关键词+搜索结果 | 口播文案（4种风格） | Step3Panel | POST /api/step3/generate |
| Step4 | 文案+视频目录 | TTS音频+标记片段（并行） | Step4Panel | POST /api/step4/audio + markers |
| Step5 | 音频+标记 | 编辑后标记（0 IO预览） | Step5Panel | PUT /api/step5/save |
| Step6 | 编辑后标记 | 裁切合并视频 | Step6Panel | POST /api/step6/cut |
| Step7 | 合并视频+音频+字幕 | 最终 mp4 | Step7Panel | POST /api/step7/compose |

## 3. 技术栈

### 后端（cut-server）
- Python 3.10+ / FastAPI / SQLAlchemy 2.x / SQLite
- edge-tts / ffmpeg / httpx / loguru / pytest

### 前端（cut-web）
- TypeScript 5+ / React 18 / Vite / Ant Design 5
- Zustand / React Router v6 / axios / Vitest / Playwright

## 4. 外部系统
- LLM: DeepSeek（默认）/ 火山云 / OpenAI（运行时配置切换）
- 搜索: Bing（默认）/ DuckDuckGo（兜底）
- TTS: edge-tts（首选）/ pyttsx3（兜底）
- 视频处理: ffmpeg + ffprobe（系统级）

## 5. 数据模型
- `vc_project`: 项目（id, title, author, intro, video_dir, intro_dir, current_step, status, output_path）
- `vc_generation_history`: 生成历史（step_num, version, result_type, result_data, status）
- `vc_config`: 全局配置（key-value）

## 6. 关键约束
- Step5 虚拟预览 0 IO 铁律（禁止 ffmpeg 操作）
- 步骤锁定（不可跳过未完成步骤）
- 长任务可取消
- 多次生成保留历史版本
- 错误码: 40xxx业务 / 50xxx服务 / 60xxx长任务
