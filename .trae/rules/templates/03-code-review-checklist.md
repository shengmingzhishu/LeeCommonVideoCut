# 精简版代码审查清单

> 从 `code-review` skill 提取的核心检查项，用于快速自检或轻量审查。
>
> 完整版请使用 `code-review` skill。

## 快速检查（5 分钟）

### 正确性（必查）

- [ ] 业务逻辑与需求一致
- [ ] 条件分支完整（无遗漏 case）
- [ ] 边界值已处理（空值、零、负数、超大值）
- [ ] 异常路径有处理（不静默吞掉）

### 安全性（必查，如有用户输入）

- [ ] 无 SQL 注入风险（参数化查询）
- [ ] 无命令注入风险（避免 shell 拼接）
- [ ] 敏感信息未写入日志（密钥、Token、个人信息）
- [ ] 权限校验存在且正确

### 代码质量（建议）

- [ ] 函数/方法不超过 50 行
- [ ] 命名清晰表达意图（不用 `temp`、`data`、`obj`）
- [ ] 无重复代码（提取公共方法）
- [ ] 有必要的注释（解释"为什么"，不是"做什么"）

### 项目规范（必查）

- [ ] 符合四层架构分层规则（见 `02-architecture-patterns.md`）
- [ ] 命名符合项目前缀规范（见 `01-project-specific.md` §1）
- [ ] 日志包含事务 ID（见 `02-architecture-patterns.md` §6.2）
- [ ] 类型注解完整（公开函数必须有）

## 评分标准

| 维度 | 通过条件 |
|------|---------|
| 正确性 | 所有必查项全部通过 |
| 安全性 | 涉及用户输入时全部通过 |
| 质量 | 建议项通过率 ≥ 80% |
| 规范 | 必查项全部通过 |

## 结论

- [ ] **PASS**：可合并
- [ ] **CONDITIONAL**：有小问题但不阻塞（列在下方的 Issues 中）
- [ ] **FAIL**：有问题必须修复后重新审查
