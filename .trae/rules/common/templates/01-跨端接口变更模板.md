## 接口定义

### 请求

| 项 | 值 |
|----|-----|
| 方法 | GET / POST / PUT / DELETE |
| 路径 | /api/xxx |
| 鉴权 | 本期放行 / Bearer Token |
| 长任务 | 否 / 是（taskId 轮询） |

### 请求体 Schema

```json
{
  "fieldName": "type — 说明 — 是否必填"
}
```

### 响应体 Schema

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "fieldName": "type — 说明"
  }
}
```
