## 8. 启动命令

```bash
cd cut-server
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
copy .env.example .env   # 编辑填入真实 MINIMAX_API_KEY
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

访问 http://localhost:8000/docs 查看 Swagger UI。
