## 三步流程接口（已实现）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/step1/outline` | 生成大纲（AI，不落库，可反复重新生成） |
| POST | `/api/step1/save` | 保存创作信息与大纲 |
| GET | `/api/step1/load` | 读取已保存的创作信息与大纲 |
| POST | `/api/step2/generate` | 生成口播长文（纯文本） |
| POST | `/api/step2/save` | 保存长文，可触发异步 TTS |
| GET | `/api/step2/load` | 读取已保存的长文 |
| GET | `/api/step3/media-list` | 音频与视频素材列表 |
| POST | `/api/step3/remark` | 对勾选视频重新随机标记 |
| POST | `/api/step3/save-state` | 保存素材选择状态 |
| POST | `/api/step3/compose` | 一键合成（异步，返回 task_id） |
| GET | `/api/creations/{cid}/outputs` | 完成页：多次合成列表（最新置顶） |
| GET | `/api/creations/{cid}/outputs/{oid}/file` | 成片在线预览 / 下载（`?download=true` 为附件；支持 Range；鉴权 + 所有权 + workdir 路径校验） |
| GET | `/api/tasks/{task_id}` | 任务详情（前端每 2 秒轮询） |
| GET | `/api/tasks` | 我的任务列表（分页） |
| DELETE | `/api/tasks/{task_id}` | 取消任务 |

## 错误码与 HTTP 状态码对应

| HTTP | 错误码示例 | 触发条件 |
|------|----------|---------|
| 401 | `AUTH_401_001` / `AUTH_401_005` | 未登录 / Token 无效 / 密码错误 |
| 402 | `MEMBER_402_001` | 会员配额不足 |
| 403 | `AUTH_403_001` / `PROJ_403_001` / `ADMIN_403_001` | 权限不足 / 资源非本人 / 非管理员 |
| 404 | `PROJ_404_001` / `CREAT_404_001` / `TASK_404_001` | 资源不存在 |
| 422 | `COMMON_422_001` / `STEP3_422_001` | 参数校验失败 / 业务前置条件不满足 |
| 500 | `COMMON_500_001` | 未预期异常（不泄露内部细节） |
| 502 | `COMMON_502_001` / `TTS_502_001` / `FILE_502_001` | 外部服务（AI / TTS / ffmpeg）失败 |
