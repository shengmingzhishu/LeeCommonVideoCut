# 跨端协作约定 · cut-server & cut-web

> 版本：v1.0 | 日期：2026-09-08
> 范围：所有前后端联动的硬规则
> 依据：`.trae/rules/shared/02-api-contract.md` + `.trae/rules/shared/03-error-code-system.md`

---

## 1. 字段命名

| 端 | 规则 | 工具 |
|----|------|------|
| 后端（cut-server） | Python `snake_case` | Pydantic + SQLAlchemy |
| 接口契约（OpenAPI） | `snake_case`（与后端一致） | 手工维护 docs/openapi.yaml |
| 前端（cut-web） | `camelCase`（TS 标准） | openapi-typescript 自动生成 |

**禁止**：前端手写 `snake_case` 字段或后端返回 `camelCase`。

## 2. 统一响应格式

```json
{
  "code": 0,
  "msg": "success",
  "data": { ... },
  "traceId": "abc123def456"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | integer | 业务状态码，0 = 成功 |
| `msg` | string | 面向用户的中文提示 |
| `data` | any | 业务数据（null 表示无） |
| `traceId` | string | 必填，前后端日志关联 |

**错误响应**（按共享规则 03）：

```json
{
  "code": "PROJ_404_001",
  "message": "项目不存在",
  "detail": "Project ID xxx not found",
  "traceId": "abc123",
  "timestamp": "2026-09-08T10:30:00Z",
  "data": null
}
```

## 3. 时间格式

| 场景 | 格式 | 示例 |
|------|------|------|
| 接口响应 | ISO 8601 字符串 | `"2026-09-08T10:30:00.123Z"` |
| 数据库存储 | PostgreSQL `TIMESTAMPTZ` | UTC |
| 前端展示 | `dayjs(value).format('YYYY-MM-DD HH:mm:ss')` | — |

**禁止**：时间戳数字、字符串拼接、locale 字符串。

---

## 4. 数字类型

| 场景 | 类型 | 传输格式 |
|------|------|---------|
| 计数/步数/页码 | `int` | number |
| 文件大小（bytes） | `int64` | number |
| 视频时长（秒） | `float` | number（保留 1 位小数） |
| 价格/金额 | `Decimal` | **string**（避免浮点误差） |
| 配额百分比 | `int` | number（0~100） |

---

## 5. 布尔字段

**使用 `is_xxx` 或 `xxx_enabled`**，禁止：

- ❌ `enabled: 1`（数字 0/1）
- ❌ `active: "true"`（字符串）

示例：
```json
{ "is_admin": true, "is_active": true, "two_factor_enabled": false }
```

---

## 6. 枚举值

**用字符串，不用数字**：

```json
{ "tier": "pro", "status": "active" }
```

**禁止**：
```json
{ "tier": 2, "status": 1 }
```

## 7. 错误码体系

格式：`{DOMAIN}_{HTTP_STATUS}_{SEQ}`

| Domain | 用途 |
|--------|------|
| `AUTH` | 鉴权（401/403） |
| `USER` | 用户 |
| `PROJ` | 项目 |
| `EPIS` | 剧集 |
| `CREAT` | 创作 |
| `STEP1~7` | 各步骤 |
| `TASK` | 任务 |
| `FILE` | 文件 |
| `CONF` | 配置 |
| `MEMBER` | 会员（402 配额） |
| `ADMIN` | 管理员权限 |
| `COMMON` | 通用（500/422/429） |

详细定义见共享层规则 `.trae/rules/shared/03-error-code-system.md`。

## 8. 鉴权头

所有需要鉴权的接口：

```
Authorization: Bearer <jwt_token>
X-Trace-Id: <trace_id>   # 可选，前端若已生成则携带
```

后端中间件：
- 缺 token → 401 + `AUTH_401_001`
- token 无效/过期 → 401 + `AUTH_401_002`
- 权限不足 → 403 + `AUTH_403_001`
- 非管理员访问 `/api/admin/*` → 403 + `ADMIN_403_001`

---

## 9. traceId 贯穿

| 端 | 行为 |
|----|------|
| 前端 axios 拦截器 | 请求时若未携带则生成 UUID，写入 `X-Trace-Id` |
| 前端 console/Toast | 报错时附 traceId，便于用户截图反馈 |
| 后端中间件 | 读取 `X-Trace-Id`，未携带则生成，写入 `request.state.trace_id` |
| 后端日志 | 每条日志必须含 `trace_id` 字段 |
| 后端响应 | 通过 `X-Trace-Id` 响应头回写 |

## 10. 分页

请求参数：
```
?page=1&pageSize=20
```

响应格式：
```json
{
  "code": 0,
  "data": {
    "page": 1,
    "pageSize": 20,
    "total": 128,
    "items": [ ... ]
  }
}
```

| 规则 | 值 |
|------|---|
| `page` 起始 | 1 |
| 默认 `pageSize` | 20 |
| 最大 `pageSize` | 100 |

## 11. 长任务异步协议

> Step4 TTS / Step6 ffmpeg / Step7 合成 都走异步。

### 11.1 提交任务

```http
POST /api/step4/generate
→ 200 { code: 0, data: { tts_task_id: "t_abc", tts_duration: null, ... } }
```

### 11.2 前端轮询

```http
GET /api/tasks/{task_id}
→ 每 2 秒一次
→ 200 { code: 0, data: { status: "running", progress: 45, ... } }
```

### 11.3 状态机

```
pending → running → completed
                  → failed
                  → cancelled
```

### 11.4 任务超时

24 小时未结束 → 自动 `failed`。

## 12. 文件路径安全

- 后端所有用户提供的路径必须经过 `utils/safe_path.py` 校验
- 工作目录限制在 `WORKDIR`（默认 `./workspace`）
- 越界直接 400 + `FILE_400_001`
