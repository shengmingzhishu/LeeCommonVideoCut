# LeeCommonVideoCut v4.0 完整设计方案

> 版本：v2.0 | 日期：2026-09-08
> 性质：项目级完整设计方案（架构 / 模块 / 数据模型 / API / UI / 权限）
> 范围：基于旧漫剧剪辑师重写为前后端分离企业级应用
> v2.0 重写：删除股票/关注/完整RBAC，改为 PostgreSQL + 简化角色（admin/user）

---

## 一、设计原则

1. **业务 100% 复刻**：旧版 7 步流程 + 项目/剧集/创作三级管理 + 历史版本 + 全部交互零损失
2. **架构前后端分离**：FastAPI（cut-server） + React（cut-web），通过 OpenAPI 契约联动
3. **企业级基础能力**：JWT 鉴权、用户体系、会员配额、管理员后台
4. **可扩展性**：模块化分层，新 Step/新业务模块按既有模式追加
5. **零硬编码业务枚举**：所有状态/会员等级走枚举类或配置
6. **零歧义接口契约**：所有接口先在 `docs/openapi.yaml` 定义，前后端严格对齐
7. **明确排除**：股票、关注、社交、在线支付均不在 v4.0 范围内

## 四、数据模型（11 张核心表 + PostgreSQL）

### 4.1 表关系图

```
users ─┬─ memberships ──── tier (free/pro/enterprise)
       ├─ projects ──── visibility
       │      └─ episodes
       │             └─ creations
       │                    ├─ step_results (current version)
       │                    ├─ generation_history (snapshots)
       │                    └─ tasks (async)
       ├─ files
       └─ configs (scope: user/global)

audit_logs ──── admin_user_id → users
usage_records ──── user_id → users (配额月度计数)
```

### 4.2 关键表 DDL（PostgreSQL 18）

```sql
-- 用户
CREATE TABLE users (
    id              VARCHAR(32) PRIMARY KEY,            -- u_xxxxxxxx
    username        VARCHAR(32) UNIQUE NOT NULL,
    email           VARCHAR(128) UNIQUE,
    password_hash   VARCHAR(128) NOT NULL,
    display_name    VARCHAR(64),
    avatar_url      VARCHAR(512),
    bio             TEXT,
    is_admin        BOOLEAN NOT NULL DEFAULT FALSE,
    membership_tier VARCHAR(16) NOT NULL DEFAULT 'free',
    is_active       BOOLEAN NOT NULL DEFAULT TRUE,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_is_admin ON users(is_admin);

-- 项目
CREATE TABLE projects (
    id          VARCHAR(32) PRIMARY KEY,                -- p_xxxxxxxx
    user_id     VARCHAR(32) NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title       VARCHAR(128) NOT NULL,
    author      VARCHAR(128),
    intro       TEXT,
    cover       VARCHAR(8) DEFAULT '🎬',
    video_dir   VARCHAR(512),
    intro_dir   VARCHAR(512),
    status      VARCHAR(16) NOT NULL DEFAULT 'active', -- active/archived
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_projects_user_id ON projects(user_id);
CREATE INDEX idx_projects_created_at ON projects(created_at DESC);

-- 剧集
CREATE TABLE episodes (
    id          VARCHAR(32) PRIMARY KEY,                -- e_xxxxxxxx
    project_id  VARCHAR(32) NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    user_id     VARCHAR(32) NOT NULL REFERENCES users(id),
    title       VARCHAR(128) NOT NULL,
    description TEXT,
    status      VARCHAR(16) NOT NULL DEFAULT 'active',
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_episodes_project_id ON episodes(project_id);
CREATE INDEX idx_episodes_user_id ON episodes(user_id);

-- 创作
CREATE TABLE creations (
    id            VARCHAR(32) PRIMARY KEY,              -- c_xxxxxxxx
    episode_id    VARCHAR(32) NOT NULL REFERENCES episodes(id) ON DELETE CASCADE,
    user_id       VARCHAR(32) NOT NULL REFERENCES users(id),
    title         VARCHAR(128),
    current_step  SMALLINT NOT NULL DEFAULT 1,
    status        VARCHAR(16) NOT NULL DEFAULT 'active',-- active/completed/failed/archived
    created_at    TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at    TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_creations_episode_id ON creations(episode_id);
CREATE INDEX idx_creations_user_id ON creations(user_id);

-- Step 结果（每步当前版本，唯一索引保证）
CREATE TABLE step_results (
    id           VARCHAR(32) PRIMARY KEY,
    creation_id  VARCHAR(32) NOT NULL REFERENCES creations(id) ON DELETE CASCADE,
    step_no      SMALLINT NOT NULL CHECK (step_no BETWEEN 1 AND 7),
    version      INT NOT NULL DEFAULT 1,
    payload      JSONB NOT NULL,
    created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (creation_id, step_no, version)
);

-- 历史快照（每次执行都 INSERT）
CREATE TABLE generation_history (
    id           BIGSERIAL PRIMARY KEY,
    creation_id  VARCHAR(32) NOT NULL REFERENCES creations(id) ON DELETE CASCADE,
    step_no      SMALLINT NOT NULL,
    version      INT NOT NULL,
    payload      JSONB NOT NULL,
    created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_history_creation_step ON generation_history(creation_id, step_no, version DESC);

-- 异步任务
CREATE TABLE tasks (
    id           VARCHAR(32) PRIMARY KEY,                -- t_xxxxxxxx
    user_id      VARCHAR(32) NOT NULL REFERENCES users(id),
    type         VARCHAR(32) NOT NULL,                   -- step1_load/step4_tts/...
    status       VARCHAR(16) NOT NULL DEFAULT 'pending',-- pending/running/completed/failed/cancelled
    progress     SMALLINT NOT NULL DEFAULT 0,            -- 0~100
    payload      JSONB,
    result       JSONB,
    error        TEXT,
    started_at   TIMESTAMPTZ,
    finished_at  TIMESTAMPTZ,
    created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_tasks_user_status ON tasks(user_id, status);
CREATE INDEX idx_tasks_created_at ON tasks(created_at DESC);

-- 文件元数据
CREATE TABLE files (
    id          VARCHAR(32) PRIMARY KEY,
    user_id     VARCHAR(32) NOT NULL REFERENCES users(id),
    path        VARCHAR(1024) NOT NULL,
    size_bytes  BIGINT NOT NULL,
    mime_type   VARCHAR(128),
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_files_user_id ON files(user_id);

-- 配置（user_id NULL = 全局）
CREATE TABLE configs (
    key         VARCHAR(64) NOT NULL,
    user_id     VARCHAR(32) REFERENCES users(id) ON DELETE CASCADE,
    value       JSONB NOT NULL,
    description TEXT,
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    PRIMARY KEY (key, user_id)
);

-- 会员分配
CREATE TABLE memberships (
    id            VARCHAR(32) PRIMARY KEY,
    user_id       VARCHAR(32) NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    tier          VARCHAR(16) NOT NULL,                  -- free/pro/enterprise
    status        VARCHAR(16) NOT NULL,                  -- active/expired/cancelled
    started_at    TIMESTAMPTZ NOT NULL,
    expires_at    TIMESTAMPTZ,                           -- NULL = 永久
    assigned_by   VARCHAR(32) NOT NULL REFERENCES users(id),
    note          TEXT,
    created_at    TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_memberships_user_id ON memberships(user_id);
CREATE INDEX idx_memberships_status ON memberships(status);

-- 用量记录（每月一条）
CREATE TABLE usage_records (
    id              BIGSERIAL PRIMARY KEY,
    user_id         VARCHAR(32) NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    year_month      VARCHAR(7) NOT NULL,                 -- '2026-09'
    step_calls      INT NOT NULL DEFAULT 0,
    storage_bytes   BIGINT NOT NULL DEFAULT 0,
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (user_id, year_month)
);

-- 管理员操作审计
CREATE TABLE audit_logs (
    id              BIGSERIAL PRIMARY KEY,
    admin_user_id   VARCHAR(32) NOT NULL REFERENCES users(id),
    action          VARCHAR(64) NOT NULL,                -- user.change_password / membership.assign / ...
    target_type     VARCHAR(32),                          -- user/membership/config
    target_id       VARCHAR(32),
    payload         JSONB,
    ip_address      VARCHAR(45),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX idx_audit_logs_admin ON audit_logs(admin_user_id, created_at DESC);
CREATE INDEX idx_audit_logs_target ON audit_logs(target_type, target_id);
```

### 5.3 错误码体系（13 域 × 7 状态）

格式：`{DOMAIN}_{HTTP_STATUS}_{SEQ}`，例 `PROJ_404_001`

| Domain | 用途 |
|--------|------|
| AUTH | 401 未登录、403 禁用账户 |
| USER | 用户不存在、改密失败、用户名重复 |
| PROJ | 项目不存在、无权访问 |
| EPIS | 剧集不存在 |
| CREAT | 创作不存在 |
| STEP1~7 | 各步骤业务错误 |
| TASK | 任务不存在、已取消 |
| FILE | 文件不存在、路径越界、上传过大 |
| CONF | 配置缺失、测试失败 |
| MEMBER | 配额不足、会员过期、会员已存在 |
| ADMIN | 仅管理员可访问 |
| COMMON | 500、422、429 |

## 七、权限模型（简化版）

| 操作 | 普通用户 | 管理员（is_admin=true） |
|------|---------|----------------------|
| 注册 / 登录 | ✅ | ✅ |
| 修改自己的资料 | ✅ | ✅ |
| 修改别人的资料 | ❌ | ✅ |
| 创建项目 | ✅（配额限制）| ✅ |
| 删除自己的项目 | ✅ | ✅ |
| 删除任意项目 | ❌ | ✅ |
| 查看自己的项目 | ✅ | ✅ |
| 查看任意项目 | ❌ | ✅ |
| 创建 / 执行 Step1~7 | ✅（配额限制）| ✅ |
| 访问 `/api/admin/*` | ❌ | ✅ |
| 分配会员 | ❌ | ✅ |
| 改全局配置 | ❌ | ✅ |
| 查看审计日志 | ❌ | ✅ |

**实现要点**：
- 不做角色枚举表，`users.is_admin` 一个布尔字段即可
- 管理员接口全部在 `/api/admin/` 前缀下，统一用 `Depends(get_admin_user)` 守卫
- 前端用 `<RequireAdmin>` 组件包裹，非管理员跳 `/403`
- 资源所有权检查在每个 controller 内显式做（`if resource.user_id != current_user.id and not is_admin: raise 403`）

## 八、关键流程时序

### 8.1 用户完整使用流程

```
1. 注册 → 自动登录 → JWT 获取
2. 创建项目（PROJ_201，配额检查）
3. 创建剧集（EPIS_201）
4. 创建创作（CREAT_201）→ current_step=1
5. Step1~7 依次执行：
   - 调对应接口 → 同步/异步任务
   - 长任务 → 返回 task_id → 前端轮询
   - 完成后存 step_results + generation_history
6. Step7 完成 → 导出 mp4（FILE_DOWNLOAD）
```

### 8.2 长任务异步流程

```
客户端 → POST /api/step4/tts
       ↓
后端 → 创建 task (status=pending)
     → 立即返回 {task_id, status: pending}
       ↓
后台 worker → 拉取 task → status=running → 执行 TTS
           → 每 2s 更新 progress
           → 完成后 status=completed + result
       ↓
客户端 → GET /api/tasks/{id}（每 2s 轮询）
       → 看到 status=completed → 取 result → 渲染
```

### 8.3 管理员分配会员流程

```
管理员 → POST /api/admin/memberships {user_id, tier, expires_at, note}
       ↓
后端 → 校验 is_admin
     → INSERT memberships（assigned_by=current_admin.id）
     → 写 audit_logs（action=membership.assign）
     → 更新 users.membership_tier
     → 返回 200
```
