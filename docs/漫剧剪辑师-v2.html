13 列含义（旧版 static/index.html 3500-3521 行）：
  1. # — 顺序号（紫色高亮当前播放行）
  2. 操作 — ▲▼ 上下移（调顺序）
  3. ● — 状态灯：绿色发光 = 正在播放
  4. 时长(s) — 该片段时长（自动计算 = end - start）
  5. 累计(s) — 从第一段累计到本段的总时长（实时）
  6. 源视频 — 视频文件名（提示框显示完整路径）
  7. 改名 — 可改显示名（不影响实际文件）
  8. 静音 — checkbox 切换该段是否静音（"静音" / "有声"）
  9. -1 — start 秒数减少 1（微调）
  10. 开始(s) — 输入框直接修改 start
  11. 结束(s) — 输入框直接修改 end
  12. +1 — end 秒数增加 1（微调）
  13. ▶ ✕ — 单独预览此段 / 删除此段
关键交互：
  • ±1 秒按钮：点击立即生效（input 同步刷新），无需按回车
  • 直接输入 start/end：onchange 触发，实时 重算 duration 与 cumulative
  • 改名：仅显示层，不影响实际文件路径
  • 静音切换：影响 Step6 合并时是否对该段降音
  • 单独预览：点 ▶ 立即用 video.currentTime 跳到 start 播放到 end
  • 删除：二次确认（Popconfirm）
性能要求：
  • 整列重新渲染需 < 100ms（≤ 50 行）
  • onchange 触发的 cumulative 重算用 useMemo 缓存
  • 长列表（> 50 行）启用虚拟滚动

M10-1 · 编辑标记时间段（弹窗）

编辑标记时间段

当前时间：00:23.4 (23.4s)
三种调整方式（核心逻辑）：
  • set（直接设置）：按上方 start/end 输入框值生效
  • add（增加）：new_start = m.start + adjust_sec, new_end = m.end + adjust_sec（整体平移）
  • sub（减少）：new_start = max(0, m.start - adjust_sec), new_end = max(new_start+0.1, m.end - adjust_sec)
实时联动：
  • start/end 输入框 oninput → duration 自动计算（不可编辑，灰色）
  • video.ontimeupdate → "当前时间" 文字实时更新
与表格行编辑的关系：
  • 表格内编辑（v2 M9 的 input/±1 按钮）：适用于精细快速调整
  • 弹窗编辑（本节）：适用于需要看源视频上下文的复杂调整
  • 两处最终都更新 m.start/m.end/m.duration，数据源一致

⭐ M11 · Step5 同步播放（核心创新）

核心价值： 音频顺序播放 + 视频按切片逐个 currentTime 切换，0 文件 IO，立即验证音频视频同步。
复用旧版： startSyncPlayS3()（旧版 3930-4000 行）。

核心逻辑

async function startSyncPlay() {
  stopAllPlaying(); _mode = 'sync';
  const audio = audioEl; const video = videoEl;

  // 1. 音频顺序播放（按 selectedAudios 列表）
  const playAudioAt = (idx) => {
    audio.src = previewUrl(selectedAudios[idx].path);
    audio.play();
    audio.onended = () => {
      if (idx+1 < selectedAudios.length) playAudioAt(idx+1);
    };
  };
  playAudioAt(0);

  // 2. 视频按切片逐个播放（核心 0 IO）
  const playNextMarker = () => {
    if (_markerIndex >= markers.length) return;
    const m = markers[_markerIndex];
    video.src = previewUrl(m.source_path);
    video.load();
    video.addEventListener('loadedmetadata', () => {
      video.currentTime = m.start;
      video.play();
      lightDot(m.id); // 状态灯点亮
    }, { once: true });

    const onEnd = () => {
      if (video.currentTime >= m.end - 0.05) {
        video.pause();
        _markerIndex++;
        lightDot(null);
        playNextMarker();
      }
    };
    video.addEventListener('timeupdate', onEnd);
  };
  playNextMarker();

  // 3. 状态栏实时更新
  statusEl.textContent = `同步播放中 · 音频 ${audioIdx+1}/${total} · 切片 ${markerIdx+1}/${markers.length}`;
}
