0. 项目概述

cut-web / cut-server v4.0 是旧版 AI漫剧剪辑师旧参考项目代码/（237 KB 单文件 HTML + FastAPI 后端）的前后端分离重构版。

核心流程： 注册/登录 → 漫剧项目 → 剧集 → 创作 → 3 大步骤（创作信息 / 口播长文 / 音视频素材）→ 合成 → 完成页（多次合成管理）→ 下载/编辑

视觉风格： 深色主题（沿用旧版 CSS 变量），紫色主色 #7c3aed + 橙色强调 #D85A30，8px 网格。

核心数据流

用户操作 → axios 请求 → JWT 拦截器注入 token
       ↓
后端 controller → service → manager → model
       ↓
异步任务（如 TTS/ffmpeg）→ task_id → 前端轮询 → 进度展示
       ↓
Step 结果 → step_results（version 自增）→ 生成历史快照 generation_history

11.4 同步播放核心算法（伪代码 · 0 IO）

// 1. 音频顺序播放
const playAudioAt = (idx) => {
  audio.src = previewUrl(selectedAudios[idx].path);
  audio.play();
  audio.onended = () => {
    if (idx+1 < selectedAudios.length) playAudioAt(idx+1);
  };
};
playAudioAt(0);

// 2. 视频按切片逐个 currentTime 切换
const playNextMarker = () => {
  const m = markers[_markerIndex];
  video.src = previewUrl(m.source_path);
  video.load();
  video.addEventListener('loadedmetadata', () => {
    video.currentTime = m.start;
    video.play();
    lightDot(m.id); // 状态灯点亮
  }, { once: true });
  const onEnd = () => {
    if (video.currentTime >= m.end - 0.05) {
      video.pause();
      _markerIndex++;
      lightDot(null);
      playNextMarker();
    }
  };
  video.addEventListener('timeupdate', onEnd);
};
playNextMarker();

25. 关键时序流

>

25.1 用户完整流程

1. 注册 → 自动登录 → JWT
2. POST /api/projects → 创建项目（配额检查）
3. POST /api/projects/:pid/episodes → 创建剧集
4. POST /api/projects/:pid/creations → 创建创作
5. Step1 → Step2 → Step3 → 完成页
6. 多次合成 → 历史记录
7. 退出

25.2 长任务流程（以 Step4 TTS 为例）

客户端 → POST /api/step4/generate
        ↓
后端 → 创建 task(status=pending)
     → 返回 task_id
        ↓
后台 worker → 拉取 task → status=running
           → 执行 TTS → 每 2s 更新 progress
           → status=completed + result
        ↓
客户端 → GET /api/tasks/:id（轮询）
       → status=completed → 取 result → 渲染

25.3 管理员分配会员流程

管理员 → POST /api/admin/memberships { user_id, tier, expires_at, note }
        ↓
后端 → 校验 is_admin
     → INSERT memberships(assigned_by=current_admin.id)
     → 写 audit_logs(action=membership.assign)
     → 更新 users.membership_tier
     → 返回 200
