## PostgreSQL 准备（阶段 1 Day 1 必做）

```bash
# 1. 确认服务运行
Get-Service postgresql-x64-18
# Status: Running ✅

# 2. 连接测试（如果 psql 不在 PATH，用 pgAdmin 或 DBeaver）
# 连接参数：localhost:5432 / postgres / 1234

# 3. 创建数据库
CREATE DATABASE cut_video
  WITH ENCODING='UTF8'
       LC_COLLATE='en_US.UTF-8'
```
