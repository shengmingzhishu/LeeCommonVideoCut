项目概述

V2.0.0
项目定位

Lee Common Stock Analysis Web 是一套面向 A 股个人投资者的多维度量化筛选 + 板块热点分析 + AI 预测辅助决策系统。系统通过 Tushare 行情数据源获取全市场股票行情、基本面财务数据和板块资金流向，结合多模型 AI 预测引擎（Gemini / DeepSeek / Claude / GPT / Qwen），为用户提供从股票筛选、估值判断、AI 预测、新闻舆情到板块热点跟踪的全链路投资辅助决策能力。

V2 版本从 V1 单体原型升级为分层架构的生产级系统：前后端分离（React SPA + Express RESTful API），5 层清晰架构（展示层 / API 网关层 / 业务服务层 / 数据访问层 / 外部服务层），支持 MySQL 持久化与 better-sqlite3 开发双引擎，通过 TanStack Query 实现服务端缓存与自动去重，React Router 7 实现 11 个 Tab 的 URL 路由化，Zustand 管理轻量全局状态，TradingView Lightweight Charts 渲染专业金融图表。

请求生命周期
  1. 用户操作：用户在浏览器中点击股票行 / 切换 Tab / 拖动滑块
  2. React Router 7：路由匹配对应页面组件，URL 同步更新（如 /stocks/600519）
  3. Zustand Store：更新全局状态（选中股票 code、当前 Tab、用户参数）
  4. TanStack Query 5：检查缓存 -- 命中则直接返回（stale-while-revalidate），未命中则发起请求；自动去重相同 key 的并发请求
  5. API Gateway（Express routes）：请求经过中间件链 -- CORS 到 请求校验 到 认证 到 路由处理
  6. Business Service：执行业务逻辑（如跌幅计算、估值灯号判定、AI 模型调度），纯 TS 无 Express 依赖
  7. Repository：数据访问层执行 SQL 查询（MySQL 生产 / sqlite3 开发），返回 ORM 映射对象
  8. External Service：如需外部数据，通过 IMktDataProvider 调用 Tushare SDK，或通过策略类调用 AI 模型
  9. 响应返回：Service 层组装 DTO 到 Express 序列化 JSON 到 前端 TanStack Query 缓存 到 React 重渲染

功能模块 1：股票列表

stocks
功能描述

模块名称

股票列表（stocks）

核心价值

展示全市场 A 股股票行情，支持悬停查看 K 线、点击选中联动、双击弹出详情。作为系统的核心枢纽模块，用户选中的股票会联动估值游标、AI 预测、新闻舆情等其他模块，实现"选中即联动"的一体化分析体验。

功能清单

  • 主表格：展示代码、名称、行业、最新价、涨跌幅、开盘价、最高价、最低价、成交量、成交额、PE、PB、总市值、是否 ST 等全维度字段，支持列排序与横向滚动
  • 悬停 K 线弹窗：鼠标悬停行时显示最近 20 日微型 K 线 SVG（蜡烛图 + 成交量柱），弹窗位置自动适配视口边界，mouseleave 后消失
  • 点击选中：单击行选中股票，高亮红色左边框，联动 AI 预测面板加载该股多模型预测、估值游标加载该股估值灯号、新闻舆情加载该股相关新闻
  • 双击详情弹窗：双击行打开 StockDetailModal，展示大 K 线（TradingView Lightweight Charts）、基本面指标卡片、风险提示标签
  • 板块和 ETF 关联：每只股票关联其所属板块名称和对应 ETF 代码/名称/收益率，用户可一键跳转至板块热点排行页
  • 风险提示：减持公告、退市风险、高质押率、立案调查等风险标签，按风险等级（高/中/低）颜色区分
  • 搜索过滤：支持按代码或名称模糊搜索，输入关键词回车后过滤匹配股票，清空恢复全部列表

V2 增强

  • TanStack Query 缓存悬停 K 线请求（防抖 300ms + 自动去重），同一股票的 K 线数据在 5 分钟内不重复请求
  • URL 反映选中股票状态（/stocks/:code），支持浏览器前进后退和分享链接
  • Zustand store 持久化选中股票 code，页面刷新后自动恢复选中状态
  • TradingView Lightweight Charts 替代自研 SVG K 线，支持缩放、平移、十字光标

功能模块 2：估值游标

valuation-gauge
功能描述

模块名称

估值游标仪表盘（valuation-gauge）

核心价值

通过股息率 5 级灯号系统，帮助用户直观判断股票当前价格是"极度便宜"还是"高估风险"。以半圆形仪表盘 + 指针的视觉形式，将抽象的估值数据转化为"红黄绿"信号灯，降低投资判断门槛。

功能清单

  • 估值卡片网格：每只股票一张卡片，展示当前价、股息率、5 年均股息率、灯号状态，支持横向滚动浏览多只股票
  • 5 级灯号系统：极度便宜（深绿）到 便宜价（浅绿）到 合理价（黄色）到 昂贵价（橙色）到 高估风控（红色），每级对应不同的股息率区间
  • 滑块调参：用户可拖动滑块调整目标股息率（0-10%），系统实时重算估值灯号并移动仪表盘指针
  • AI 诊股：调用 Gemini AI 生成智能诊断总结，结合财务数据给出"建议买入/观望/减持"的文字建议
  • 估值价格区间：显示便宜价、合理价、昂贵价三个基准价格，用户可直观看到当前价位于哪个区间
  • 距离便宜价百分比：显示当前价距便宜价的涨幅空间，正值表示还需涨、负值表示已超过便宜价

V2 增强

  • 用户自定义参数（目标股息率、灯号阈值）持久化到 MySQL，刷新后恢复
  • AI 诊断支持多模型切换（Gemini / DeepSeek / RandomMock），通过策略类调度
  • TanStack Query 缓存 AI 诊断结果，5 分钟内不重复调用

功能模块 3：AI 预测面板

ai-predictions
功能描述

模块名称

AI 预测和胜率榜（ai-predictions）

核心价值

多模型矩阵对比 + 5 日推荐回测，辅助投资决策。系统不依赖单一 AI 模型，而是让 5 个模型（Gemini-3.1-Pro / DeepSeek-V3 / Claude-3.5-Sonnet / GPT-4o / Qwen-2.5-Max）对同一股票做出预测，通过横向对比和历史回测准确率，帮助用户识别哪些模型在哪些股票上更可靠。

功能清单

  • 多模型矩阵：5 个 AI 模型对同一股票的预测对比，每模型展示预测方向（看涨/看跌/震荡）、置信度百分比、预测目标价格
  • 3 日预测回测：每模型最近 3 天的预测方向 vs 实际涨跌，标注对错（绿色对勾 / 红色叉号），计算该模型对该股的短期准确率
  • 模型准确率：每模型对该股票的历史准确率 + 胜场/总场数据，帮助用户判断哪个模型在该股上更可靠
  • 5 日推荐榜：最近 5 个交易日的 AI 推荐股票列表 + 推荐后涨跌幅 + 盈亏判断（盈利/亏损），用户可追溯推荐表现
  • 股票准确率排行：按 AI 预测准确率排序的股票列表，找出"AI 最擅长预测的股票"
  • 综合建议：综合多模型投票结果给出买入/观望/减持建议，多数模型看涨则建议买入，多数看跌则建议减持

V2 增强

  • AI 预测记录持久化到 MySQL（重启不丢失），可追溯历史预测准确率
  • 多模型策略类设计（GeminiStrategy / DeepSeekStrategy / RandomMockStrategy），模型可热插拔
  • TanStack Query 缓存多模型预测结果，10 分钟 stale time

功能模块 4：新闻舆情

news-alerts
功能描述

模块名称

新闻和预警利好（news-alerts）

核心价值

聚合个股新闻舆情，自动分类利好/利空/中性，评估影响力分数。帮助用户在信息过载的市场中快速识别对持仓或关注股票有重大影响的新闻事件，辅助短期交易决策。

功能清单

  • 新闻列表：个股新闻卡片流，含标题、摘要、影响分析、发布时间，按时间倒序排列
  • 三级分类：利好（BULLISH，红色标签）/ 利空（BEARISH，绿色标签）/ 中性（NEUTRAL，灰色标签），通过 NLP 自动分类
  • 影响力评分：-10 到 +10 的影响力分数，正值表示利好程度，负值表示利空程度，绝对值越大影响越显著
  • 关联板块：每条新闻关联其涉及的板块名称，用户可点击跳转到板块热点排行
  • 点击跳转：点击新闻卡片可跳转到对应股票详情页，查看该股的完整分析
  • 分类筛选：支持按利好/利空/中性分类筛选，快速聚焦某一类信息

功能模块 6：跌幅筛选器

filter-drop
功能描述

模块名称

跌幅筛选器（filter-drop）

核心价值

筛选指定天数内跌幅超过阈值且底部横盘的股票，捕捉超跌反弹机会。通过可调参数（天数 + 跌幅阈值）和底部横盘判断算法，帮助用户在超跌股中识别真正企稳的标的，避免"接飞刀"风险。

功能清单

  • 参数调节：天数滑块（30-120 天，默认 70 天）+ 跌幅阈值滑块（10%-50%，默认 20%），实时更新筛选结果
  • 筛选结果表格：展示代码、名称、行业、最高价、最高日、低位天数、最低价、当前价、相对位置（距最低价涨幅）、最大跌幅、是否底部横盘
  • 板块和 ETF 关联：每只结果关联板块走势，帮助判断是否为板块系统性下跌
  • 底部横盘判断：最近 3 天收盘价均高于最低价，判定为"底部横盘"（绿色标签），否则为"仍在下跌"（红色标签）
  • 相对位置可视化：以进度条显示当前价在最高价和最低价之间的相对位置，直观判断反弹程度

核心算法

遍历指定天数内的日 K 线数据，找到最高价和最低价，计算最大跌幅 = (最高价 - 最低价) / 最高价。若最大跌幅超过阈值，则进一步判断底部横盘：取最近 3 天的收盘价，若均高于最低价则标记为底部横盘。

功能模块 7：跌停筛选器

filter-limit-down
功能描述

模块名称

跌停筛选器（filter-limit-down）

核心价值

筛选指定天数内跌停且连续反弹的股票，捕捉跌停后反弹机会。通过区分主板（-10%）和创业板/科创板（-20%）的不同跌停阈值，精确识别不同市场板块的跌停反弹模式。

功能清单

  • 参数调节：天数滑块（1-10 天，默认 5 天）+ 市场类型选择（主板/创业板/科创板/全部），自动适配跌停阈值
  • 双创差异：创业板和科创板跌停阈值为 -20%，主板为 -10%，系统根据股票代码前缀自动判断市场类型
  • 筛选结果表格：展示代码、名称、行业、当前价、跌停次数、最后跌停日、反弹天数、反弹幅度、今日涨跌幅
  • 板块和 ETF 关联：每只结果关联板块走势，判断是否为板块系统性风险导致的跌停
  • 反弹追踪：从最后跌停日起计算反弹天数和反弹幅度，帮助用户判断反弹力度

核心算法

识别跌停日：当日 pctChange 小于等于跌停阈值（主板 -10% / 创业板科创板 -20%）。统计指定天数内的跌停次数和最后跌停日。从最后跌停日起计算反弹天数（连续收盘价高于跌停日收盘价的天数）和反弹幅度（当前价 / 跌停日收盘价 - 1）。
