🔄 v3 关键变更（基于用户反馈 + 旧版源码验证）

  1. 步骤从 7 个合并为 3 个：经查证旧版 static/index.html 第 1985 行 STEP_NAMES = ['', '创作信息', '口播长文', '音视频素材']，确认旧版实际就是 3 个主步骤。新版对齐此设计：
    • Step 1 创作信息 = 原 Step1（基础表单）+ Step2（AI拆解+搜索）+ Step3（口播长文）
    • Step 2 音视频素材 = 原 Step4（TTS + 视频标记）+ Step5（虚拟预览）+ Step6（裁切合并）
    • Step 3 合成 = 原 Step7
  2. 新增"完成页"（旧版没有的概念）：多次合成可回看与下载，方便用户返回上一步微调再合成
  3. 步骤内子模块用标签页（Tabs）组织，而不是硬切页面跳转

Tab 切换规则：
  • 已完成 Tab：紫色 ✓ 标记，可来回切换修改
  • 当前 Tab：紫色下划线
  • 未完成 Tab：灰色，不可点击

解锁规则：
  • 必须按顺序：填基础信息 → AI拆解 → 口播长文

"保存并进入 Step 2"按钮：
  • 前提：3 个子模块都有结果（满足任一即可进入，但强烈建议全部完成）
  • 点击后：保存所有子模块 → 跳 Step 2

🔄 多次合成的核心设计

用户完成 Step 3 后，会跳到一个专门的"完成页"，而不是停留 Step 3 或回到项目列表。

完成页包含：

  1. 当前最新合成（置顶高亮）
  2. 历史合成列表（按时间倒序，可滚动）
  3. 一键返回 Step 1 或 Step 2（继续修改 → 再次合成 → 生成新记录）
  4. 每个合成可单独预览/下载/删除
复用价值： 用户经常需要"试不同风格的合成"（不同分辨率 / 不同烧字幕开关 / 不同字幕样式）。多次合成让用户对比效果，选择最佳版本发布。
历史价值： 所有历史合成记录保留，可随时下载旧版本（防止误操作丢失）。
协作价值： 管理员/会员可看到所有历史合成，便于复盘。

"继续编辑 →"按钮（关键）：
  • 点击后：跳回 Step 1 或 Step 2（用户选择保留哪些参数）
  • 用户改完再回来 → 点击"重新合成" → 生成新版本（v4）
  • 旧版本（v1/v2/v3）仍保留在历史列表中
3 种继续编辑入口（用户原话"适合编辑"）：
  • 点"复制配置" → 用 v3 的所有参数（分辨率、字幕样式）新建一次合成 → 适合微调
  • 点"继续编辑 →" → 跳到 Step 1/2 改文案/标记 → 改完重新合成
  • 直接点列表中的"编辑"列 → 跳到对应 Step 编辑
"重新合成"按钮逻辑：
  • 基于当前最新的 step_results（不是某个旧版本）
  • 用新参数合成 → 生成 v4（按版本号递增）
  • 旧版本在历史中保留，不会被覆盖
用户原话"多次的合成展示在合成列表中"：
  • 历史列表按时间倒序（最新在上）
  • 当前选中的版本有高亮边框（绿色）
  • 每个版本独立预览/下载
  • 可"删除"（仅本人可见，且需二次确认）
下载方式（多选项）：
  • 浏览器下载（默认）→ 保存到下载文件夹
  • 保存到素材目录（带时间戳+标题）→ 方便管理
  • 保存到指定目录（自定义）→ 高级用户
