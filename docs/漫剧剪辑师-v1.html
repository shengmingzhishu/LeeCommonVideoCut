项目概述

项目名： cut-web（漫剧推广素材剪辑师前端）
目标： 基于旧版 AI漫剧剪辑师旧参考项目代码/static/index.html 重写为 React + TS + Vite + AntD + Zustand 的前后端分离应用。
业务核心： 7 步视频剪辑向导（输入 → AI 拆解 → 口播文案 → 双线并行 → 虚拟预览 → 裁切合并 → 合成导出）
用户体系： 注册/登录、个人中心、会员等级（Free/Pro/Enterprise）、管理员后台
设计原则： 1:1 复刻旧版视觉风格（深色主题 / 紫色主调 / 橙色强调），不"设计升级"

技术栈

类别选型
语言TypeScript 5+（strict 模式）
UI 框架React 18（函数组件 + Hooks）
构建Vite 5
组件库Ant Design 5（CSS 变量覆盖为暗色主题）
路由React Router v6（懒加载）
状态Zustand（轻量全局状态）
HTTPaxios + 拦截器（traceId/token/错误统一处理）
样式CSS Modules + Sass（沿用旧版 CSS 变量）
图表ECharts（按需引入，股票模块预留位）
测试Vitest + Playwright

核心数据流

用户操作 → axios 请求 → JWT 拦截器注入 token
↓
后端 controller → service → manager → model
↓
异步任务（如 TTS/ffmpeg）→ task_id → 前端轮询 → 进度展示
↓
Step 结果 → step_results 表（version 自增）→ 生成历史快照 generation_history

显式排除（NOT in scope）

  • ❌ 关注系统、粉丝、动态流
  • ❌ 股票行情、自选股、K 线
  • ❌ 完整 RBAC（角色-权限-资源）
  • ❌ 在线支付集成
  • ❌ 公开用户主页 / 评论 / 点赞
  • ❌ 邮件 / 短信通知

这是产品最复杂的组件，必须严格按以下交互实现：
  • 播放：用 video.currentTime 切换，setTimeout 精确控制片段时长，不产生任何文件 IO
  • 片段增删：右侧列表右键菜单 / ⋮ 按钮弹出
  • 片段拖拽：支持调整顺序
  • 时间段编辑：双击进入编辑模式，input 框输入 start/end
  • 时长匹配检查：差异 ≥ 2 秒时高亮（黄色警告）
  • 倍速切换：0.5x / 1x / 1.5x / 2x
  • 键盘快捷键：Space 播放/暂停，← → 切片段
  • 移动端：片段列表改为底部抽屉
性能要求：
  • 预览启动延迟 < 200ms
  • 拖拽帧率 ≥ 30fps（用 requestAnimationFrame）
  • 长列表用虚拟滚动
