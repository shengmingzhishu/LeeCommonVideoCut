# video-cut · 接口契约（API Contract）

> **本文档是前后端开发的唯一权威依据。**
> 后端实现必须严格按本文档的路径 / 方法 / 请求体 / 响应体；
> 前端 `src/types/api/` 中的 TS 类型必须与本文档的 Schema 一一对应；
> 任何字段增减、类型变更、路径调整都必须先改本文档，再改两侧代码。

> **基础信息**
> - Base URL（开发期）：`http://localhost:8000/api`
> - 数据格式：JSON（UTF-8）
> - 鉴权：本期默认放行；预留 `Authorization: Bearer <token>` header，后端在 `vc_config.auth_enabled=true` 时校验
> - Trace：所有请求必须带 `X-Trace-Id` header（前端 axios 拦截器自动注入），后端日志记录

## 0. 通用规范

### 0.1 统一响应格式

```json
{
  "code": 0,
  "msg": "ok",
  "data": { ... }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 成功；非 0 失败（见 §0.3 错误码） |
| msg | string | 提示信息，成功为 "ok" 或自定义文案，失败为错误描述 |
| data | object \| null | 业务载荷，无数据时为 null |

HTTP 状态码固定 **200**，错误信息放在 `code` 字段（与 `AI漫剧剪辑师旧参考项目代码` 对齐）。

### 0.2 通用请求头

| header | 必填 | 说明 |
|--------|------|------|
| `Content-Type` | 是（POST/PUT） | `application/json` |
| `X-Trace-Id` | 否 | 前端注入的链路追踪 ID |
| `Authorization` | 否 | `Bearer <token>`，本期默认不校验 |

### 0.3 错误码体系

| 范围 | 含义 | 示例 |
|------|------|------|
| 0 | 成功 | 0 |
| 40001 | 参数缺失 / 校验失败 | 40001 |
| 40101 | 项目不存在 | 40101 |
| 40102 | 步骤锁定（前置未完成） | 40102 |
| 40103 | 素材资源不存在 / 不可读 | 40103 |
| 40104 | 任务不存在 | 40104 |
| 40105 | 历史版本不存在 | 40105 |
| 50001 | AI 调用失败 | 50001 |
| 50002 | 搜索失败 | 50002 |
| 50003 | TTS 失败 | 50003 |
| 50004 | ffmpeg/ffprobe 失败 | 50004 |
| 50005 | IO 错误（文件读写） | 50005 |
| 50006 | 内部异常（兜底） | 50006 |
| 60001 | 长任务失败 | 60001 |
| 60002 | 长任务已取消 | 60002 |
| 60003 | 长任务超时 | 60003 |

错误响应示例：

```json
{ "code": 40101, "msg": "项目不存在", "data": null }
```

### 0.4 时间格式

所有时间字段统一 ISO 8601 字符串（带时区）：

```
2026-08-23T14:30:00+08:00
```

后端 Pydantic 用 `datetime` 字段，前端 TS 用 `string`（解析时转 `Date`）。

### 0.5 ID 格式

- 项目 ID：UUID v4 字符串
- 历史版本 ID：UUID v4 字符串
- Task ID：`{prefix}_{uuid_short}`，前缀：`audio` / `mark` / `cut` / `compose`

## 2. 项目管理（vc_project）

> **设计原则**：项目即创作，扁平化，无旧参考的 `episodes` / `creations` 双层。
> 一个 `Project` 对应一次"漫剧推广视频"的全流程产出。

### 2.1 Project 数据模型

```typescript
interface Project {
  id: string;                  // UUID
  title: string;               // 漫剧标题
  author: string;              // 作者
  intro: string;               // 简介（100~500 字）
  videoDir: string;            // 视频素材目录绝对路径
  introDir: string | null;     // 介绍资料目录（可空）
  currentStep: number;         // 当前步骤 1~7
  status: ProjectStatus;       // draft / processing / completed / failed
  outputPath: string | null;   // 最终成品路径
  coverPath: string | null;    // 封面图路径（可空，预留）
  createdAt: string;           // ISO 8601
  updatedAt: string;           // ISO 8601
}

type ProjectStatus = 'draft' | 'processing' | 'completed' | 'failed';
```

### 2.2 接口清单

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/projects` | 项目列表（支持搜索/筛选/分页） |
| POST | `/api/projects` | 新建项目 |
| GET | `/api/projects/{project_id}` | 项目详情（含每步当前结果摘要） |
| PUT | `/api/projects/{project_id}` | 更新项目元数据 |
| DELETE | `/api/projects/{project_id}` | 删除项目（含中间产物） |
| POST | `/api/projects/{project_id}/duplicate` | 复制项目 |
| POST | `/api/projects/{project_id}/reset` | 重置进度到 Step1（保留元数据） |

### 2.3 GET /api/projects

**Query 参数**：

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | string | 否 | 按标题模糊搜索 |
| status | string | 否 | 按状态筛选：`draft/processing/completed/failed` |
| page | int | 否 | 页码，从 1 开始，默认 1 |
| page_size | int | 否 | 每页条数，默认 20，最大 100 |

**响应 data**：

```typescript
{
  total: number;
  page: number;
  pageSize: number;
  items: Project[];
}
```

### 2.4 POST /api/projects

**请求体**：

```typescript
interface ProjectCreate {
  title: string;           // 必填，1~100 字
  author: string;          // 必填，1~50 字
  intro: string;           // 必填，100~500 字
  videoDir: string;        // 必填，本地绝对路径
  introDir?: string;       // 可选
}
```

**响应 data**：`Project`

**校验**：
- `videoDir` 必须存在且可读
- `videoDir` 必须至少含 1 个 `.mp4` / `.mov` / `.avi` 文件
- `introDir` 若提供则必须存在

### 2.5 GET /api/projects/{project_id}

**响应 data**：

```typescript
{
  project: Project;
  stepResults: StepResultSummary[];   // 每步当前结果摘要，按 step_num 排序
  taskRunning: TaskStatus | null;       // 当前是否有运行中的任务
}
```

`StepResultSummary`：

```typescript
interface StepResultSummary {
  stepNum: number;          // 1~7
  version: number;          // 当前版本号
  status: 'success' | 'failed';
  resultType: string;       // load / analyze / script / audio / markers / edit_markers / cut_video / final
  updatedAt: string;
}
```

### 2.6 PUT /api/projects/{project_id}

**请求体**：`Partial<ProjectCreate>`（所有字段可选）

**响应 data**：`Project`

**约束**：
- `currentStep` 只能通过 `reset` 或后续步骤推进修改，本接口不允许直接改
- 若项目已完成（status=completed），禁止修改任何字段（需先 reset）

### 2.7 DELETE /api/projects/{project_id}

**响应**：`{ code: 0, msg: "ok", data: null }`

**副作用**：
- 删除 `vc_project` 行
- 删除 `vc_generation_history` 中该 project 的所有行
- 删除 `data/workspace/projects/{project_id}/` 整个目录

### 2.8 POST /api/projects/{project_id}/duplicate

**请求体**：

```typescript
{
  newTitle: string;         // 复制后的标题
  copyStepResults?: number[]; // 要复制的步骤号列表，默认复制 1~7 全部（不含 final mp4）
}
```

**响应 data**：新 `Project`

**说明**：复用元数据 + 已生成的文案/标记，**不复制最终 mp4**（用于 A/B 测试不同剪辑）。

### 2.9 POST /api/projects/{project_id}/reset

**请求体**：

```typescript
{
  keepHistory?: boolean;    // 是否保留生成历史，默认 true
}
```

**响应 data**：`Project`（current_step=1, status=draft）

**副作用**：
- 若 `keepHistory=false`：删除该项目所有生成历史
- 不删除工作目录（用户可手动重跑 Step1~7 覆盖）

## 3. 全局配置（vc_config）

### 3.1 Config 数据模型

```typescript
interface Config {
  // AI 大模型
  aiProvider: 'deepseek' | 'volcano' | 'openai';  // 默认 deepseek
```

## 4. 7 步流程接口

> **通用约定**：
> - 每个步骤接口都需要 `project_id`（路径或请求体）
> - 短任务（<3s）同步返回；长任务（>3s）返回 `{task_id}`，前端轮询 `/api/task/{task_id}`
> - 每个步骤完成后 INSERT 一条 `vc_generation_history`（version 自增）
> - 步骤锁定：当前置步骤未完成（无 success 记录），后端返回 `40102`

### 4.1 Step1 输入信息 + 知识库加载

#### 4.1.1 POST /api/step1/load

**请求体**：

```typescript
interface Step1LoadRequest {
  projectId: string;          // 必填
  reloadKb?: boolean;         // 是否强制重新读取介绍资料，默认 false
}
```

**同步响应 data**：

```typescript
{
  videoCount: number;         // 素材视频文件数
  totalDuration: number;      // 素材总时长（秒）
  kbPath: string;             // 知识库路径
  docCount: number;           // 已加载介绍文档数
}
```

**副作用**：
- 读取 `videoDir` 下所有 `.mp4/.mov/.avi`，ffprobe 取时长
- 若 `reloadKb=true` 或首次：读取 `introDir`（若存在）下所有 `.txt/.md`，写入知识库
- 写 `vc_generation_history(result_type='load')`
- 更新 `vc_project.current_step = 2`（解锁 Step2）

#### 4.1.2 GET /api/step1/materials?project_id=xxx

**响应 data**：

```typescript
{
  videoCount: number;
  totalDuration: number;
  videos: Array<{
    filename: string;
    path: string;
    duration: number;
    sizeBytes: number;
  }>;
}
```


**副作用**：
- ffmpeg 合并 Step6 视频 + Step4 音频
- 基于 timestamps.json 生成 SRT
- 字幕烧录（`-vf subtitles=sub.srt`）
- 写 `vc_generation_history(result_type='final')`
- 更新 `vc_project.status = 'completed'`, `output_path = ...`

#### 4.7.2 POST /api/step7/cancel

**请求体**：

```typescript

```

**响应 data**：`{ cancelled: boolean }`

## 7. 文件交互

### 7.1 GET /api/file/preview

**Query 参数**：

| 名称 | 必填 | 说明 |
|------|------|------|
| path | 是 | 视频/音频文件绝对路径 |
| token | 否 | 本期预留 |

**响应**：流式二进制，支持 HTTP Range（前端 `<video>` seek 必需）

**Content-Type**：根据文件后缀返回 `video/mp4`、`audio/mpeg` 等

**校验**：路径必须在 `vc_project.video_dir` 或 `workspace/` 下，防越权

### 7.2 GET /api/file/download

**Query 参数**：

| 名称 | 必填 | 说明 |
|------|------|------|
| path | 是 | 文件绝对路径 |

**响应**：`Content-Disposition: attachment; filename=xxx` 流式下载

### 7.3 GET /api/dir/browse

**Query 参数**：

| 名称 | 必填 | 说明 |
|------|------|------|
| path | 否 | 起始目录，默认系统盘根（如 `C:\` 或 `/`） |
| mode | 否 | `dirs`（只目录）/ `files`（只文件）/ `all`（默认 `dirs`） |

**响应 data**：

```typescript
{
  current: string;                // 当前绝对路径
  parent: string | null;          // 上级路径
  entries: Array<{
    name: string;
    path: string;
    isDir: boolean;
    sizeBytes?: number;
    ext?: string;
  }>;
}
```

**安全约束**：
- 只返回磁盘上存在的目录/文件
- 不暴露系统关键目录（Windows: `C:\Windows`、`C:\Program Files` 等；Unix: `/etc`、`/var`、`/usr` 等）
- 前端用于"素材目录选择器"
