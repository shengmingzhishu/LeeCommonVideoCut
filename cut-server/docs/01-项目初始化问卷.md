## 1. 项目基本信息

- **项目名称**：video-cut
- **项目描述**（一句话说明做什么）：本地化的"漫剧/视频推广素材一键生产工具"，7 步流程自动生成可发布的 mp4 推广视频。
- **项目目标**（要解决什么问题）：

## 4. 业务领域

- **核心功能**（按 7 步流程）：
  1. **Step1 输入项目信息**：标题、作者、简介、视频素材目录；扫描素材、加载知识库
  2. **Step2 AI 拆解关键词 + 搜索文章**：核心词、价值点、建议标题、搜索关键词 + 1~5 篇文章
  3. **Step3 生成抖音口播长文**：含折叠大纲，支持文案风格/目标时长配置
  4. **Step4 双线并行**：
     - 音频线：edge-tts 合成口播 mp3 + 时间戳
     - 视频标记线：扫描素材 → ffprobe 时长 → 随机标记时间段（3~8s/段，目标时长 = 音频时长 + 2s）
  5. **Step5 虚拟预览 + 编辑标记**：前端纯 seek，0 IO；编辑起止/删除/拖拽/时长匹配检查
  6. **Step6 按标记裁切 + 合并视频**：ffmpeg 真正切片 + concat 合并为 1080×1920 无音轨 mp4
  7. **Step7 音视频合成 + 字幕烧录** → 导出最终 mp4
  8. **项目管理**：多项目 CRUD、复制、删除、进度恢复、生成历史回看/对比/回滚
  9. **配置管理**：API Key、TTS 引擎/语音、搜索引擎、模型选择等持久化
- **业务约束**：
  - 本地优先：TTS / 视频处理均本地化，无需云服务
  - 视频素材 = 多个大原视频（mp4/mov/avi），不是已切好的短片段
  - 每段时长 3~8s 随机（节奏自然）
  - 标记总时长 = 音频时长 + 2s（留余量，用户手动确认调整，不自动平衡）
  - 真正的 ffmpeg 裁切只在 Step6 用户确认后执行一次
  - 每次生成 INSERT 一条历史（version 自增），不覆盖旧结果
  - 数据库只存路径 + 元数据，文件在 `workspace/projects/{project_id}/`
  - 风险兜底：edge-tts → pyttsx3；Bing → DuckDuckGo；DeepSeek → 火山云/OpenAI
- **数据模型提示**（3 张表，详见 `01-project-specific.md` §6.1）：
  - `vc_project`（项目元数据）：id(UUID), title, author, intro, video_dir, intro_dir, current_step, status, output_path, created_at, updated_at
  - `vc_generation_history`（生成历史，version 自增）：id, project_id, step_num, version, result_type, result_data(JSON), status, duration_ms, created_at
  - `vc_config`（全局配置 key-value）：key, value, updated_at

## 附录：与旧参考代码的差异要点（避免直接复用）

1. **架构差异**：旧参考是"单 HTML + Python 后端"混合（一个 FastAPI 应用同时挂静态文件 + API），新项目是**前后端分离**，前端独立部署在 `cut-web/`。
2. **数据库表命名**：旧参考用复数（`projects`, `episodes`, `creations`），新项目按本规则 §6.1 用单数 + `vc_` 前缀（`vc_project`, `vc_generation_history`, `vc_config`）。
3. **删除冗余实体**：旧参考有 `episodes`（剧集）+ `creations`（创作）两个层级，新项目只保留 `vc_project`（项目即创作），更扁平。
4. **去掉 auth 强制中间件**：旧参考有强制登录中间件，本期定位是本地工具，**预留 token 字段但默认放行**；用户可在 `vc_config` 自行开启。
5. **错误码**：旧参考用裸 HTTP 状态码（401/422/500），新项目统一走 `{code, msg, data}` 中 `code` 字段，HTTP 状态码固定 200。
6. **CORS**：旧参考 `allow_origins=["*"]`，新项目限定 `http://localhost:5173`（Vite 默认端口），生产部署时按需调整。
