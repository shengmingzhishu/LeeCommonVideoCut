# 项目上下文（video-cut · 后端）

> AI 启动开发前的必读摘要。完整规则见 `.trae/rules/`，详细 PRD 见 `AI漫剧剪辑师旧参考项目代码/docs/PRD-漫剧推广素材剪辑师.md`。

## 1. 项目一句话

本地化"漫剧/视频推广素材一键生产工具"的后端服务（Python + FastAPI），7 步流程自动生成可发布的 9:16 竖屏推广 mp4。

## 4. 命名速查

- 数据库表：`vc_project`, `vc_generation_history`, `vc_config`（单数 + `vc_` 前缀）
- Python 类：`Project`, `ProjectService`, `ProjectManager`, `VideoCutError`
- 路由前缀：`/api/step{1~7}/...`
- 工作空间：`data/workspace/projects/{project_id}/{kb|audio|video|output}/`
- 中间产物：`{title}_audio.mp3`, `{title}_silent.mp4`, `{title}_final.mp4`, `markers.json`, `timestamps.json`

## 5. 接口契约（与前端共用）

- Base URL：`http://localhost:8000/api`
- 响应格式：`{code, msg, data}` — `code=0` 成功，其余失败
- HTTP 状态码固定 200（错误信息放在 `code`）
- 长任务：提交→返回 `{task_id}` → 前端轮询 `/api/task/{task_id}`
- 大文件：DB 仅存路径，前端经 `/api/file/preview` Range 流式拉取

错误码体系（详见 `01-project-specific.md` §4）：

| 范围 | 含义 |
|------|------|
| 0 | 成功 |
| 4xxxx | 客户端错误（参数缺失/资源不存在/步骤锁定） |
| 5xxxx | 服务端错误（AI/TTS/ffmpeg/IO 失败） |
| 6xxxx | 长任务专属（任务失败/取消/超时） |

## 6. 7 步领域速查

| Step | 服务 | 关键产物 |
|------|------|---------|
| 1 | step1_service | 扫描素材 → `vc_generation_history.result_data={video_count,total_duration,kb_path}` |
| 2 | step2_service | AI 拆解 + 搜索 → `{core_keywords,value_points,suggested_titles,search_keywords,articles}` |
| 3 | step3_service | 口播文案 → `{script,outline,word_count,est_duration}` |
| 4 | step4_service | 双线并行：`audio_path,timestamps_path` + `markers_path,marker_count,total_duration` |
| 5 | step5_service | 保存编辑后的标记 → `markers_edited_path,final_markers` |
| 6 | step6_service | ffmpeg 裁切+合并 → `video_path,duration,segment_count` |
| 7 | step7_service | 合成+字幕 → `output_path,duration,file_size,srt_path` |

## 7. 关键技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 数据库 | SQLite（标准库） | 单文件零依赖，本地工具 |
| ORM | SQLAlchemy 2.x 同步 | 与 sqlite3 同步访问匹配，简单 |
| 异步任务 | `asyncio.create_task` + 后台字典 | 任务量小，避免 Celery 复杂度 |
| 视频处理 | ffmpeg 子进程 + ffmpeg-python 封装 | 仅 Step6/7 真正切片 |
| TTS | edge-tts 优先 + pyttsx3 兜底 | 音质 vs 离线可用性 |
| AI | OpenAI 兼容协议（httpx） | 统一接口，可换 DeepSeek/火山云/OpenAI |
| 配置 | 环境变量 > vc_config 表 > 代码默认 | 敏感 key 入 DB，普通配置走 env |

## 9. 卡点恢复机制（精简）

- 单个 bug 修复 3 次仍失败 → 暂停，落到 `docs/03-问题记录.md`，等待人工
- 接口契约变更 → 必须同步更新 `cut-web/src/types/api/`，并在 PR 中说明
- 数据库 schema 变更 → 必须更新 `.trae/rules/server/common/05-database-migrations.md` + `cut-server/docs/03-问题记录.md`
