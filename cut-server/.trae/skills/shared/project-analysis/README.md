# Local Project Analyzer

本地项目智能分析器（VS Code Copilot 版）

## 概述

该技能用于分析整个项目目录，输出技术栈、架构、依赖、质量评分和改进建议，适用于代码审查、项目评估与设计文档沉淀。

此版本重点优化为 Copilot Agent 直接执行：
- 默认分析整个项目（不再依赖外部脚本主流程）
- 通过技能内约束完成大部分统计与判断
- 每次分析都必须生成一个 Markdown 主报告文件

## 使用方式

在对话中触发：

```text
分析项目
生成项目文档
评估项目质量
```

可选参数：
- focus_dir
- include_tests
- analysis_depth (quick | standard | deep)
- output_dir
- overwrite

## 输出约定（强制）

- 默认输出目录：项目根目录下 文档
- 默认文件名：项目分析-{YYYYMMDD-HHmmss}.md
- 必须产出：1 个 Markdown 主报告
- 可选附加产物：依赖图 Mermaid 代码块、质量评分卡、索引等

## 分析内容

- 技术栈识别：语言、框架、构建与测试工具
- 架构分析：目录结构、模块边界、架构模式
- 依赖分析：直接依赖、潜在风险、关键依赖
- 质量评估：文档、测试、规范、安全、可维护性
- 最佳实践建议：高/中/低优先级改进清单

## 质量评分维度

- 代码组织（0-5）
- 文档完整性（0-5）
- 测试完整性（0-5）
- 代码规范（0-5）
- 安全性（0-5）
- 可维护性（0-5）

综合评分输出等级：A、A-、B、B-、C、D。

## 与历史版本差异

- 由脚本驱动改为 Copilot 工具链驱动
- 耗时场景优先使用降级策略（quick 模式）
- 保留原有分析维度与描述语义
- 强化文档落地能力，确保可留存 Markdown 产物

## 目录说明

- SKILL.md：技能主定义（执行约束与流程）
- references/：技术栈和架构识别参考
- scripts/：历史脚本实现（可参考，不作为默认主路径）
- assets/：可复用模板资产
