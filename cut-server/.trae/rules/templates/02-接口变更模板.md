# 接口变更模板

> 新增或修改 API 接口时填写此模板，供 Code Review 和联调参考。

## 基本信息

| 字段 | 内容 |
|------|------|
| 变更类型 | □ 新增接口 □ 修改接口 □ 废弃接口 |
| 接口路径 | `METHOD /api/xxx` |
| 所属模块 | Controller / Service |
| 影响范围 | 前端 / 第三方 / 内部 |
| 变更原因 | （为什么需要这个变更） |

## 接口定义

### 请求

```yaml
method: GET | POST | PUT | PATCH | DELETE
path: /api/{resource}/{id}
headers:
  Authorization: "Bearer {token}"
  Content-Type: "application/json"

# 请求体（POST/PUT/PATCH）
body:
  type: object
  required:
    - name
  properties:
    name:
      type: string
      description: 名称
      example: "测试套件A"
    direction:
      type: string
      enum: [text_qa, sql_correctness, rag_scoring]
      description: 评测方向
```

### 响应

**成功响应 (200)**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "uuid",
    "name": "测试套件A",
    "direction": "text_qa",
    "created_at": "2026-09-03T10:00:00Z"
  }
}
```

**错误响应**：

| HTTP 状态码 | code | message | 触发条件 |
|-------------|------|---------|---------|
| 400 | 40001 | 参数校验失败 | 缺少必填字段 / 格式错误 |
| 401 | 40101 | 未授权 | Token 缺失或过期 |
| 403 | 40301 | 无权限 | 非资源所有者 |
| 404 | 40401 | 资源不存在 | ID 无效 |
| 500 | 50001 | 服务器内部错误 | 未预期异常 |

## 变更影响

### 前端影响

- [ ] 无需前端改动
- [ ] 需要前端适配（说明具体变更）
- [ ] 需要前端联调（联系人：___）

### 数据库影响

- [ ] 无 Schema 变更
- [ ] 新增表/字段：（说明）
- [ ] 需要数据迁移脚本：（是/否）

### 兼容性

- [ ] 向后兼容（旧客户端可继续使用）
- [ ] 破坏性变更（需协调发布顺序）

## 安全检查

- [ ] 接口有鉴权校验（除非是公开接口）
- [ ] 输入参数已校验（防注入、XSS）
- [ ] 敏感信息不在响应中返回
- [ ] 操作日志已记录（含事务 ID）
- [ ] 权限校验正确（用户只能操作自己的数据）

## 示例调用

```bash
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "测试套件A", "direction": "text_qa"}'
```
